# Privacy policy

Last updated: November 14, 2026

Hardcode Dark Mode changes website colors according to rules you choose. It has no developer-operated servers, analytics, advertising, or remote code.

## Website access

The extension processes page structure, element attributes, and rendering information in your browser to select elements and apply themes. Open tab and frame URLs are checked to locate configured sites; the extension does not keep a browsing-history log. Themes apply only to sites you add to the library.

Page contents, browsing activity, and theme rules are not sent to the developer or third parties by the extension.

This information is used only to provide the theme controls you choose. It is not sold or used for advertising, profiling, or unrelated purposes. Hardcode Dark Mode's use of user information complies with the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies#limited-use), including its Limited Use requirements.

## Saved settings

Your site library and rules stay in Chrome's local extension storage. These settings include website origins, enabled states, selected modes, element selectors, rule names, exceptions, and creation dates. Selectors and labels can contain information derived from the elements you select.

Language and library sorting preferences use Chrome's sync storage. If Chrome Sync is enabled, Chrome may synchronize these preferences through your Google account under Google's privacy practices. The site library and element rules do not use sync storage.

## Export and deletion

Export saves a JSON file containing your library, rules, preferences, and an export date to a location you choose. Import reads the file you select. These actions do not upload the file to the developer. Treat exported settings as private because they can identify websites and elements you use.

You can remove a site and its rules from the library. Chrome normally removes local extension storage when you uninstall the extension. Exported files remain until you delete them; Chrome controls retention of synchronized preferences.

## Permissions

- **Website access:** finds configured sites in open documents and frames, and applies their saved themes. Access is requested for HTTP and HTTPS websites so you can choose sites without a separate permission prompt for each one.
- **Scripting:** registers and injects the packaged theme engine and element-selection tools.
- **Storage:** saves the settings described above.

## Contact

For questions, use the [project's issue tracker](https://github.com/YanGranat/Hardcode_dark_mode/issues). Do not post settings exports or private page content in a public issue.
